# v0.5 Legacy Documentation Snapshot

This directory preserves the pre-v1 software philosophy as a retrospective archival edition.

The **v0.5** label denotes the legacy doctrine generation. It does not claim that every historical commit was literally tagged 0.5.0 at the time.

That generation emphasized:
- Rust;
- TOML as a declarative product surface;
- Docker;
- release tooling;
- quality gates;
- AI as an editor/operator.

v1.0 retains useful operational ideas but moves the central abstraction upward: authority, repository memory, transactional work, macro-goals, evidence, and director/worker coordination are technology-independent first-class concepts.

Do not edit archived files to make them agree with v1.0. Historical disagreement is part of the record.
