# Human verification request

Before asking the principal to test, resolve the repository-native execution path.

Preferred form:

> Pull accepted `main`. Dependencies [did/did not] change. [Run `<repo dependency command>` first / no dependency refresh is needed.] Then run `<repo QA/build command>` from the repository and check `<specific embodied behavior>`. Report only what you observe; the repo should retain logs.

Never substitute a generated CI/agent download bundle for the repository execution surface.
