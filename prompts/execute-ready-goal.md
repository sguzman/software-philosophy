# Worker invocation

Preferred prompt:

> Read AGENTS.md and execute the single authorized macro-goal in docs/work/ready/. Continue through all authorized diagnosis, implementation, repair, and validation passes until the acceptance gates pass or the goal's escalation conditions require stopping. Commit and push the required report and leave the repository in the handoff state specified by the goal.

The repository carries the actual contract. Do not paste the whole goal into the prompt unless the worker cannot access the repository.
