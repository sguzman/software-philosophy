# Director review invocation

Preferred prompt:

> Inspect the repository's pushed candidate branch for the completed goal. Review it against the goal contract, canonical architecture, current project doctrine, and reported evidence. Accept, reject, revise, or block it. If accepted, integrate it and update current status and roadmap as needed. If revision is needed, write a durable bounded review contract in the repository.

The human should not need to paste the worker's report when the director can inspect the repository directly.
