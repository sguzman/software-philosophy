# Director review invocation

Preferred prompt:

> Inspect the repository's pushed candidate branch for the terminalized attempt. Review it against the repository macro-goal contract, canonical project architecture, software architecture doctrine, relevant principal profiles, current project doctrine, and reported evidence. Accept, reject, revise, or block it. If accepted, integrate it and update current status and roadmap as needed. If revision or correctable rejection is needed, preserve the same repository goal ID unless the semantic objective itself is superseded, write a durable bounded correction contract, reopen the same goal to ready, specify branch/report continuation, and state that a fresh worker session is required if the prior session has terminated.

The human should not need to paste the worker's report when the director can inspect the repository directly.

A new worker/Codex Goal session is not, by itself, a new repository macro-goal.
