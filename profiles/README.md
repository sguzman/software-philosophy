# Principal Implementation Profiles

Profiles record current technology defaults for the principal.

They are stronger than casual preference but weaker than universal software law.

A profile answers:

> Given a new project with no contrary constraint, what implementation environment should the director assume?

Current profiles:
- `rust-first.md` — Rust is the default implementation language; non-Rust is mainly for configuration, shell/platform integration, package-manager/build metadata, or cases where Rust is genuinely not the right/available host.

Profiles use the **CURRENT CONVENTION** modality.

They may be revised by explicit principal/director decision.
